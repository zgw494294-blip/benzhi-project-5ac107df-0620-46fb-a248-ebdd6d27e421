# StageCaption

StageCaption 是面向剧场无障碍服务团队的字幕排演与播出锁版工作台。它把台本时间基准、字幕段落、确定性规则检查、排演问题、整改复演、独立复核和播出包固化到一条带修订历史的流程中。浏览器页面与 JSON API 均由 Go 服务直接提供，不需要 Node 构建链。

项目状态按 `草稿 → 待校验 → 待排演 → 整改中 → 待复核 → 已锁版` 推进。字幕编辑按场次取得短期租约，并以项目修订号提交；复核锁版前会建立项目写屏障。SQLite 保存项目、字幕、检查发现、排演证据、历史快照、租约、审计记录和锁版元数据。锁版后的 WebVTT、JSON 清单和摘要凭据从不可变快照确定性生成。

工作台还提供带风险摘要的项目队列筛选、场次字幕批量粘贴入轨、质量发现筛选定位、排演问题分场统计与复演窗口、多字幕联合整改、复核区间字段级差异和锁版门禁清单。锁版后既可在服务端复算摘要，也可回选实际下载的三个文件，逐文件核对格式、元数据和跨文件 SHA-256 摘要链；文件回读验真是只读操作。

所有批量编辑都沿用项目修订号和场次租约保护，并在单个 SQLite 事务中只生成一个新修订。查询、预检和播出包验真不会修改项目状态、修订号或审计记录。

## 构建与运行

```text
go build ./cmd/server
go run ./cmd/server -addr=127.0.0.1:19081
```

默认监听 `127.0.0.1:19081`，工作台地址为 `http://127.0.0.1:19081/workbench`。可以通过 `-addr=127.0.0.1:<port>` 指定回环地址，也可以设置 `PORT`（仅填写端口号），服务随后绑定 `127.0.0.1:<PORT>`。服务拒绝非回环监听地址。

默认数据库文件是 `stagecaption.db`，可通过 `-db=<path>` 指定其他 SQLite 文件。

## 测试与自检

```text
go test ./...
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

`-selfcheck` 会建立临时 SQLite 数据库，在传入的真实监听地址上启动同一套 HTTP 服务，并经由 JSON API 走完建档、租约编辑、校验、带阻断问题的排演、整改复演、独立复核、锁版、下载和摘要验证。流程有超时限制，完成后会自动关闭服务并清理临时数据。
